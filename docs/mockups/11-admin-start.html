안전한 하루 · 관리자

교육 증빙 작성에 쓰던 2시간을 5분으로 줄이는 것이
이 시스템을 쓰는 현실적인 이유입니다.

어떤 일로 들어오셨나요

로그인하면 담당자 대시보드로 들어갑니다.

운영자 계정은 2단계 인증을 거칩니다. 문구 라이브러리는 모든 안전 지시의 근거이므로 계정 하나가 뚫리면 전 사업장에 영향이 갑니다.

가입 후 사업장 · 공정 · 설비 · 노동자 언어 등록을 한 번 마치면 이후 모든 교육이 그 구성을 기준으로 만들어집니다. 여기서 넣지 않은 언어는 어떤 화면에서도 제공되지 않습니다.

이 시스템이 하는 일과 하지 않는 일

합니다 — 교육 실시를 돕고, 무엇을 어느 언어로 얼마나 이해했는지 기록해 감독관에게 낼 교육일지를 자동으로 만듭니다.

하지 않습니다 — 법정 안전교육의 공식 인정 기관을 대체하지 않습니다. 노동자의 위치·근태를 기록하지 않고, 이해도 점수를 인사·평가 목적으로 내보내지 않습니다.

근거
  • SCREEN 2. 기능 상세 — 담당자는 기능1·2·5·6, 운영자는 기능9. 로그인 뒤 도착 화면이 달라 역할을 먼저 고른다
  • PRD §3.2 페르소나 C — 40인 공장 생산팀장이 안전 업무를 겸직한다. 직책 선택지에 “겸직”을 그대로 둔다
  • PRD §2.2 — 증빙 문서 작성 2시간 → 5분. 도입의 현실적 유인이라 첫 화면에 내건다
  • PRD §2.3 비목표 — 공식 인정 기관을 대체하지 않고 교육 실시를 보조·기록한다
  • PRD §9.2 · §10 — 위치·근태 미기록, 점수의 인사·평가 내보내기 없음을 담당자에게도 먼저 밝힌다
  • SCREEN 기능9 — 문구 라이브러리는 “제품 신뢰의 단일 최대 요인”이라 운영자 로그인에 2단계 인증을 붙였다
  • SCREEN 기능1 — 등록되지 않은 언어는 이후 어떤 화면에서도 제공되지 않는다는 경고를 가입 단계에 둔다
  • 제품 문구에 “면책” 표현을 쓰지 않는다 (PRD §10)
