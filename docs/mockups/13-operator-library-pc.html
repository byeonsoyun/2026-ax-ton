이 화면이 왜 중요한가

노동자와 담당자 어느 쪽 화면에도 보이지 않지만, 기능2의 교육 콘텐츠와 기능7의 현장 지시가 쓰는 모든 문장의 근거가 여기서 나옵니다. 여기서 통과한 문구만 안전 지시가 되므로, 판정 하나가 전 사업장에 그대로 전달됩니다.

근거
  • SCREEN 기능9 (F-08) — 문구 목록 → 언어별 번역 등록 → 검수 요청 → 검수 승인 → 배포 / 오역 신고 처리
  • SCREEN 기능9 AI — 초기 번역 초안, 역번역 대조로 의미 왜곡 후보 표시, 음성 합성. 판정은 사람 몫이라 화면 맨 위에 경계를 적었다
  • SCREEN 기능9 데이터 — 검수 상태 3종(검수 완료 / 검수 대기 / 사용 중지)과 검수자 기록을 표에 그대로 옮겼다
  • SCREEN 기능9 해설 — “검수 완료가 아닌 문구는 어떤 화면에서도 안전 지시로 노출되지 않는다”, “오역 신고가 접수되면 즉시 사용 중지한다”
  • SCREEN 기능9 해설 — 사용자에게 보이지 않지만 제품 신뢰의 단일 최대 요인
  • SCREEN §4 · 기능7 — 문구 200개가 오프라인으로 동작해야 하므로 전체 모수를 200으로 뒀고, 배포에 오프라인 캐시 갱신을 포함했다
  • PRD §9.3 — 원어민 검수를 거친 문구만 사용, 역번역 검토, 오역 신고 채널을 노동자·담당자 양쪽에 제공, 접수 시 즉시 사용 중지
  • PRD §10 — 안전 문구 오역은 영향도 “치명적” 리스크. 그래서 오역 신고 큐를 본문 맨 위에 뒀다
