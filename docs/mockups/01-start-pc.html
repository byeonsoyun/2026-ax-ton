근거
  • 화면.txt 1~3행 — 일반 사용자 › 시작화면 › 로그인/회원가입
  • PRD §8.2-1 — 언어는 최초 1회 선택 후 기억한다
  • PRD §9.2 — 외국인등록번호·여권번호 미수집, 사업장 내 익명 ID 사용
  • PRD §10 — 개인정보 미수집을 자기 언어로 첫 화면에서 고지 / 개인 기기를 강제하지 않고 공용 태블릿 경로를 함께 제공
  • PRD §9.1 — 공용 태블릿 병행 사용이 전제이므로, 화면이 넓어져도 터치 타깃 60×60px 를 그대로 지킨다
  • PC 적응 — 모바일에서 위아래로 쌓았던 “서비스 설명 → 고지 → 폼”을 좌우 2단으로 펴고, 짧은 입력(사업장 코드·이름 등)은 두 칸으로 묶었다
  • 제품 문구에 “면책” 표현을 쓰지 않는다 (PRD §10)
