## 4. 데이터 10칸과 그 계약

**화면 코드는 `localStorage` 를 직접 부르지 않습니다.** 반드시 `Store` 를 거칩니다.
**직접 부르는 코드가 `store.js` 밖에 없는지를 자동 검사가 매번 확인합니다.**

```
[화면 11개]  →  [ Store ]  →  지금: 브라우저 저장소
                    ↑
              서버가 생기면 이 안쪽만 서버 호출로 바꿉니다.
              화면 11개는 한 줄도 안 고쳐도 됩니다.
```

| # | 키 | 무엇 | 쓰는 쪽 | 읽는 쪽 |
|---|---|---|---|---|
| 1 | `accounts` | 계정 | 회원가입 | 로그인 · 게시판(역할 판정) |
| 2 | `session` | 지금 로그인한 사람 | 로그인 | 모든 화면(가드) |
| 3 | `setup` | 사업장·언어·공정·설비·노동자 | 기능1 | 거의 전부 |
| 4 | `library` | 안전 문구 + **언어별** 검수 상태 | 기능9 | 기능2 · 기능3 · 홈 |
| 5 | `courses` | 교육과 문항 | 기능2 | 기능3 · 기능4 · 5 · 6 |
| 6 | `progress` | 누가 무엇을 듣고 몇 점인지 | 기능3 · 기능4 | 기능5 · 기능6 · 마이 |
| 7 | `reports` | 위험요소 신고 (**익명**) | 기능8 | 기능6 |
| 8 | `posts` | 게시글·댓글 | 기능7 | 기능7 |
| 9 | `prefs` | **이 기기**의 보기 설정 (글자 크기) | 노동자 아무 화면 | 노동자 전부 |
| 10 | `orders` | 담당자의 **재교육 지시** | 기능6 | 노동자 홈 · 기능6 |

### 4.1 모양이 미묘한 세 곳

**① `library[].translations[code].status` — 언어별 검수**

```js
{ id: 'ph-3', ko: '환기팬이 돌지 않으면 …', status: 'reviewed',
  translations: {
    km: { text: '…', back: '…', status: 'reviewed' },
    id: { text: '…', back: '…', status: 'stopped' }   // 이 언어만 중지
  },
  flags: [ { note: '…', lang: 'id', at: '…', resolvedAt: null } ] }
```

읽을 때는 **반드시 `Store.phraseOk(p, lang)`**. `p.status` 를 직접 보면
**크메르어 노동자가 인도네시아어 오역 때문에 안전 지시를 잃습니다.**
문구 전체와 언어별 판정이 다르면 **엄한 쪽**(중지 > 대기 > 완료)을 따릅니다.

**② `courses[].quiz[].i18n` — 문항 다국어**

```js
{ id: 'q2', type: 'choice', prompt: '…', options: ['…','…','…'], answer: 1,
  i18n: { km: { prompt: '…', options: ['…','…','…'], results: [...] } } }
```

읽을 때는 **반드시 `Store.qtext(q, lang, field)`**.
**`answer` 는 `options` 의 인덱스**라, 번역 배열 길이가 다르면 정답이
다른 선택지를 가리키고 **틀린 작업을 맞다고 가르칩니다.**
그 검사는 `qtext` **한 곳에만** 있습니다.

**③ `progress[].quiz.asked` — 답이 어느 문항의 것인가 (C6 에서 추가)**

```js
quiz: { score: 67, passed: false, answers: [0,1,1], asked: ['q1','q2','q3'],
        at: '…', attempt: 2, firstPassed: true }
```

`answers` 의 자리는 **"그때 실제로 낸 문항"** 의 순서지 `course.quiz` 의 자리가
아닙니다. 문항을 하나 내리면(`retired`) 그 뒤에 푼 사람의 답이 **한 칸씩 밀립니다.**
읽을 때는 **반드시 `Store.askedQuestion(course, quizRow, i)`**.
`asked` 가 없는 옛 기록은 지금까지처럼 자리로 찾습니다.

### 4.2 데이터 모양을 바꿔야 한다면

1. `store.js` 의 그 키 주석부터 고칩니다 (거기가 계약서입니다)
2. **그 키를 읽는 화면을 전부** 엽니다 (위 표)
3. **읽는 통로를 함수 하나로 모읍니다** (`phraseOk` · `qtext` · `askedQuestion` ·
   `orderOpen` 이 전부 그렇게 생겼습니다). 화면마다 흩어 놓으면 언젠가 한 곳이 빠집니다
4. 검사를 돌리고, **일부러 망가뜨려** 그 검사가 잡는지 봅니다

| **검증** `worker/quiz` ★ | 문항 3유형 — 👆hotspot(설비 그림에서 위험 지점 짚기) · ☑choice(올바른 작업) · 🔗match(보호구 연결) · **내 언어 문항** · 한 문항에 한 번만 · 답한 직후 **"어떤 사고가 되는지"** · 미통과 시 **"노동자의 실패가 아니라 교육의 실패"** · 결과를 `progress` 에 (asked 포함) |
| **신고** `worker/report` | 설비·위험유형을 **그림으로** 고르고 메모 · **완전 익명**(식별값 저장 0) |

- "내린 문항을 계속 낸다" 를 **아무 검사도 안 잡고** 있었음

## 8. 함정 모음 — 여기서 여러 번 다쳤습니다

개발일지에서 뽑았습니다. **같은 함정에 두 번 빠지지 않게** 여기 모읍니다.

### 8.1 데이터·판정

| 함정 | 무엇이 일어났나 | 규칙 |
|---|---|---|
| **수강한 날로 기간을 거름** | 아직 아무것도 안 한 사람은 날짜가 없어 **통째로 빠짐**. 이수율이 저절로 올라감 | 기준은 **발급일(`course.createdAt`)** |
| **답을 자리(index)로 문항에 짝지음** | 문항을 내리면 한 칸씩 밀려 **대시보드가 다른 문항의 숫자를 말함** | `Store.askedQuestion` |
| **`p.status` 를 직접 봄** | 한 언어의 오역으로 다른 언어 노동자가 안전 지시를 잃음 | `Store.phraseOk(p, lang)` |
| **`update()` 콜백에서 값을 return** | 그 값이 저장소를 **통째로 덮음**. 라이브러리가 날아간 적 있음 | 아무것도 return 하지 않기 |
| **해소 여부를 `orders` 에 저장** | 진실이 두 곳이 됨 | `progress` 를 보고 판정 (`Store.orderOpen`) |
| **"통과했으면 해소" (시점 무시)** | 예전에 통과한 사람에게 지시를 보내면 **보내자마자 사라짐** | 지시를 **내린 뒤**에 통과해야 해소 |

### 8.2 화면·접근성

| 함정 | 규칙 |
|---|---|
| 배지를 눈에만 보이게 | **글을 못 읽는 사람에게는 없는 정보.** 음성에도 넣기 (아이콘은 빼고) |
| 버튼만 조용히 없애기 | 사람은 그것을 **고장으로** 읽음. **왜 못 하는지 화면에 적기** |
| 다시 그릴 때마다 배지를 새로 끼워 넣기 | 배지가 쌓임. **자리를 HTML 에 정해 두기** (`#today-note`) |
| 막다른 끝 (넘기기가 끝에서 멈춤) | 고장으로 보임. **한 바퀴 돌기.** 볼 것이 하나면 버튼을 통째로 감추기 |
| `ui.js`(문서 끝)에서 글자 크기 적용 | 기본 크기로 한 번 그려졌다 커짐 → **저시력 사용자에게 "안 보이는 화면"**. `store.js` 가 `<head>` 에서 |
| 기능은 만들었는데 **들어갈 길이 없음** | C7 이 그랬음. 진입로와 **나올 길**을 함께 만들기 |
| 누르면 튕기는 버튼 | 담당자에게 노동자 탭바가 그대로 떠 있었음. **튕기는 것과 돌아가는 것은 다름** |

### 8.2-1 음성 되돌림

| 함정 | 규칙 |
|---|---|
| **뜻이 안 닿는 소리를 내기** | 소리는 나는데 아무것도 전달되지 않으면 사람은 **"들었다" 고 넘어간다.** 그 언어 음성이 없으면 **안 내고, 왜 안 내는지 적는다** (`UI.voiceSilent` · `voiceNote`) |
| **되돌림을 아예 없애기** | 말은 알아듣는데 **글만 못 읽는 사람**에게는 한국어 음성이 유일한 통로. 없애지 말고 **고르게** 한다 (`prefs.voiceFallback`) |
| **기본을 `ko` 로 두기** | 기본이 되돌림이면 이 기능이 있는 이유가 사라짐. 기본은 **`silent`** |
| **한국어를 되돌림 대상으로 보기** | **한국어도 노동자의 언어다.** `voiceSilent()` 는 `ko` 에 늘 거짓. 한국어 사용자에게 "번역 준비 중" 배지도 안 띄움 (`needsTranslation()`) |
| **골라도 화면이 안 따라옴** | 새로고침해야 바뀌는 설정은 **바뀌지 않는 설정과 구분되지 않음.** `UI.notifyVoice()` 로 알림 |
| **aria-label 에 원인을 하나로 뭉뚱그리기** | 원인이 둘(브라우저 / 내 언어 음성). 화면 낭독기 쓰는 사람에게는 그것이 이유의 전부. `voiceNote()` 와 **한 통로** |
| **`ui.js` 의 되돌림 표와 사전이 갈림** | 관리자 화면은 `i18n.js` 를 안 읽어서 `VOICE_NOTE_KO` 를 씀. **`test-voicefallback.js` 가 양방향으로 대조** |

### 8.3 검사

| 함정 | 규칙 |
|---|---|
| 통과 개수가 늘어난 것으로 만족 | **일부러 망가뜨려** 잡히는지 보기 |
| 검사가 **우연히** 통과 | 다른 필터에 먼저 걸려서. **그 조건만 남기고** 다시 짜기 |
| 주석이 **있지도 않은 검사**를 가리킴 | `ui.js` 가 없는 `test-voice.js` 를 가리키고 있었음. **주석이 가리키는 파일 이름 자체를 검사**하기 |
| 검사에 **한국어 글자를 박음** | 화면이 노동자의 언어로 바뀌면 깨짐. **번역을 막는 검사**가 됨. `I18N.t(키, 언어)` 로 견주기 |
| `rows[0]` 처럼 **자리로 찾기** | 예시 데이터에 사람이 한 명 늘면 조용히 **다른 사람**을 봄. **아이디로 찾기** |
| 실패가 **예외로 죽음** | 다음 줄이 `undefined.length` 를 읽음. `(x || [])` 로 감싸 **실패가 실패로 보이게** |
| 개수에 바닥을 두는 검사 | 일을 끝낼 때마다 숫자를 내리게 됨. **숫자를 내리는 검사는 아무것도 지키지 않음** |
| 날짜가 지나면 썩는 단정 | `'D-'` 를 기대하면 기한이 지난 뒤 깨짐. **"미정이 아니다"** 처럼 |
| 검사 쪽에서 코드의 표를 가져다 씀 | 표가 틀려도 **둘이 사이좋게 틀림**. 검사 쪽에 따로 적기 |

### 8.4 환경

| 함정 | 규칙 |
|---|---|
| ES 모듈 | `file://` 에서 CORS. `var X = (function(){...})()` |
| 절대경로 `/assets/...` | `file://` 에서 깨짐. **상대경로** |
| 줄바꿈(CRLF/LF) | 저장소 파일은 CRLF. 검사에서 여러 번 걸림 |
| JS 정규식 `\w` 에 한글이 안 들어감 | `replace(/^\W+/,'')` 로 **한글까지 잘림**. `[^가-힣\d]` |
| jsdom 은 화면을 안 그림 | CSS 는 **글로 읽어** 확인 |
| `location` 흉내에 `origin` 없음 | 하네스에 더해 뒀음 |
| **`String.replace` 의 치환문에 `$$`** | JS 에서 `$$` 는 **리터럴 `$` 하나**를 뜻함. `UI.$$` 가 `UI.$` 로 조용히 바뀌어 화면 하나가 죽었음. 치환문에 `$` 가 있으면 **함수 형태**로: `s.replace(a, () => b)` |
| **셸 힙독이 백슬래시를 먹음** | `\b` `\s` 가 든 정규식을 힙독으로 넘기면 한 겹 사라져 다른 뜻이 됨. 그런 내용은 **Write 로 직접** 쓰기 |

### 8.5 다국어 (UI-1)

| 함정 | 규칙 |
|---|---|
| **i18n 사전에 안전 지시를 넣음** | 사전은 **검수를 안 지난다.** "손을 넣지 마십시오" 가 들어오면 검수를 우회하는 통로가 생김. `test-i18n.js` 가 말투로 막음 |
| **HTML 에서 한국어 원문을 지움** | JS 가 멈추면 **화면이 통째로 빔.** `data-i18n` 만 달고 원문은 남겨 둠 |
| **검수 전 고지를 화면마다 띄움** | 늘 떠 있으면 **무시하게 됨.** 내 언어를 고르는 자리 한 곳에만 |
| **검사에 한국어 글자를 박음** | 번역이 될수록 검사가 깨짐. `I18N.t(키)` 로 견줌 |
| **관리자 화면까지 번역** | 반쪽짜리 번역이 섞이는 것이 더 나쁨. 노동자 화면만 |
| **새 화면을 만들고 i18n.js 를 안 읽음** | 그 화면만 한국어로 남음. `test-i18n.js` 가 6화면 전부 확인 |

### 8.6 음성 신고

| 함정 | 규칙 |
|---|---|
| **녹음을 저장** | 목소리는 사람을 식별함. **익명 신고가 익명이 아니게 됨.** 글자만 저장하고 오디오는 어디에도 안 담음. `MediaRecorder` 가 코드에 들어오면 `test-voice.js` 가 잡음 |
| **안 되는 브라우저에서 버튼 감추기** | 사람은 **고장으로 읽음.** 왜 안 되는지 적고 손으로 쓰는 길을 남김 (V4 와 같은 규칙) |
| **옮긴 글을 바로 보내기** | **받아쓰기는 틀림.** 고칠 수 있는 칸에 넣고, 담당자 화면에도 "말한 것을 옮김" 을 적음 |
| **한국어로 알아듣게 두기** | `rec.lang` 을 그 사람의 언어로. 음성 낭독과 **같은 표(`VOICE_TAG`)** 를 씀 |
| **오프라인인데 되는 척** | 받아쓰기는 인터넷이 필요함. `UI.listenProblem()` 이 미리 판정하고 화면에 적음 |
| **마이크를 켜 둔 채 화면을 떠남** | `pagehide` 에서 멈춤 |

### 8.7 오프라인 (E1)

| 함정 | 규칙 |
|---|---|
| **`sw.js` 를 `assets/` 아래에 둠** | scope 가 `/assets/` 로 좁아져 **화면을 하나도 못 잡음**. 배포 루트(`src/sw.js`)에 |
| **캐시 키에 쿼리가 붙음** | `learn.html?course=c-press` 는 `learn.html` 과 **다른 키**. **QR 로 들어온 노동자만** 오프라인에서 빈 화면 | 
| **담을 목록에 새 파일을 빠뜨림** | 온라인에서는 멀쩡해서 사람 눈으로 못 잡음. `tests/test-offline.js` 가 `src/` 와 대조 |
| **`skipWaiting()`** | 보던 중에 파일이 갈려 **옛 HTML + 새 JS** 반쪽 화면 | 
| **`VERSION` 을 안 올리고 배포** | 고쳤는데 안 고쳐진 것으로 보임. Service Worker 의 가장 흔한 사고 |
| **"오프라인 가능" 을 고정 문구로 박음** | `file://` 이나 아직 안 담긴 상태에서도 그렇게 말함 → **화면이 거짓말**. `UI.offlineReady()` 로 실제 `controller` 를 보고 그림 |
| **`file://` 에서 등록을 시도** | 부르는 것만으로 예외가 나는 브라우저가 있음. **`https:` 검사 + `try/catch` 둘 다** |

