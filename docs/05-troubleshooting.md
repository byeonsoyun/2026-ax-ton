## 코드 관련

### 화면이 하얗게 뜬다 / 아무것도 안 나온다

거의 항상 JavaScript 오류입니다.

1. 브라우저에서 **F12** 를 누릅니다 (Mac 은 `Cmd + Option + I`)
2. 위쪽 탭에서 **Console** 을 누릅니다
3. **빨간 글씨**를 통째로 복사해서 Claude Code 에 붙여넣습니다

> `Uncaught ReferenceError: Store is not defined` 처럼 나오면
> `<script>` 태그 순서가 틀린 것입니다. `store.js` → `auth.js` → `ui.js` → 화면 JS 순서여야 합니다.

### 로그인했는데 계속 로그인 화면으로 돌아온다

계정이 없는 상태입니다. 로그인 화면의 **`예시 데이터 채우기`** 를 누르세요.

혹은 브라우저가 시크릿 모드일 수 있습니다. 일반 창에서 여세요.

### 내 화면에 들어가려는데 다른 화면으로 튕긴다

**정상입니다.** 역할이 안 맞으면 자기 역할의 첫 화면으로 돌려보냅니다.

| 내 화면 | 로그인할 계정 |
|---|---|
| `worker/` 아래 전부 | `W-4821-07` |
| `admin/dashboard` `content` `proof` `setup` | `kim@daesung.co.kr` |
| `admin/library` | `oper@safety.kr` |

비밀번호는 전부 `1234` 입니다.

### 저장한 게 사라졌다

데이터는 브라우저 안에만 있고, **주소가 달라지면 저장소도 따로 놉니다.**

- `file:///C:/...` 로 연 것과 `localhost` 로 연 것과 `vercel.app` 이 전부 별개입니다
- 시크릿 모드는 창을 닫으면 사라집니다
- 브라우저 "사이트 데이터 삭제"를 하면 함께 사라집니다

**고장이 아닙니다.** 예시 데이터를 다시 채우면 됩니다.

옮기고 싶으면 설비 등록 화면(`admin/setup.html`) 우측의 **`내보내기`** 로 JSON 을 복사해서
다른 쪽에서 **`불러오기`** 하세요.

### 스타일이 하나도 안 먹는다

CSS 경로가 틀렸습니다. 하위 폴더에서는 `../assets/style.css` 처럼 **점 두 개**로 시작해야 합니다.

`/assets/style.css` 처럼 슬래시로 시작하면 `file://` 로 열었을 때 깨집니다.

## git 관련

> **원칙: 직접 치지 말고 Claude Code 에게 시키세요.**
> 아래는 무슨 일이 일어나는지 이해하기 위한 설명입니다.

### 충돌(conflict)이 났다고 뜬다

두 사람이 **같은 파일의 같은 줄**을 고쳤을 때 납니다.

**혼자 해결하려 하지 마세요.** Claude Code 에게 이렇게 말하세요.

> 충돌이 났어요. 어떤 파일인지 보고 어떻게 하면 좋을지 알려 주세요.

파일이 **내 담당이 아니면** 관리자에게 알리세요. 남의 작업을 지울 수 있습니다.

> **예방법**: 매일 작업 시작할 때 최신 코드를 받으면 충돌이 거의 안 납니다.
> Claude 가 알아서 하지만, 며칠 쉬었다면 시작할 때 `최신 코드 받아 주세요` 라고 한 번 말해 주세요.

### push 가 안 된다 — 권한 오류

```
remote: Permission to byeonsoyun/2026-ax-ton.git denied
```

저장소에 초대를 못 받았거나 GitHub 로그인이 안 된 상태입니다.
**관리자에게 저장소 초대(Collaborator)를 요청**하세요.

### push 가 안 된다 — rejected

```
! [rejected] ... (fetch first)
```

내가 push 하기 전에 누가 먼저 올린 것입니다. Claude Code 에게 말하세요.

> push 가 거절됐어요. 최신 것 받아서 다시 올려 주세요.

### 브랜치를 잘못 갔다

`main` 이나 `develop` 에서 작업하면 안 됩니다.

지금 어디인지 확인:

```
git branch --show-current
```

내 브랜치로 이동 (이름만 바꿔서):

```
git checkout feature/본인이름
```

> **이미 `main` 에서 파일을 고쳐 버렸다면** 옮기기 전에 Claude Code 에게 말하세요.
> 그냥 `checkout` 하면 고친 내용이 따라오거나 막힐 수 있습니다.

### 남의 파일을 고쳐 버렸다

당황하지 말고 Claude Code 에게 말하세요.

> 제 담당이 아닌 파일을 고친 것 같아요. 어떤 파일인지 확인하고 되돌려 주세요.

아직 push 하지 않았으면 쉽게 되돌립니다. push 했으면 관리자에게 알리세요.

### 내 담당이 뭔지 모르겠다

[02-positions.md](02-positions.md) 의 배정표를 보세요.
거기에도 내 이름이 없으면 관리자에게 물어보세요.
