# A. 데이터 모양을 바꾸는 것 — 먼저

**왜 먼저인가** — 아래 둘은 저장 데이터의 모양을 넓히는 일이고, `quiz.js` `content.js`
`learn.js` `library.js` `proof.js` `home.js` 를 건드립니다.
값싼 것부터 하면 **같은 파일을 두 번 엽니다.**

- [ ] **A1. 문항 다국어화** — `courses.quiz[].i18n`

  - **어디**: `assets/store.js` (헬퍼) · `assets/seed.js` · `worker/quiz.js` ·
    `admin/content.js` · `admin/proof.js`
  - **무엇**: 문항에 `i18n: { km: { prompt, options, results }, id: {...} }` 를 더합니다.
    한국어 필드는 그대로 남고, 그 언어가 없으면 한국어로 내려갑니다.
    읽는 통로는 `Store.qtext(q, lang, field)` 와 `Store.qhas(q, lang)` 하나로 모읍니다
  - **왜**: 기능4는 **"문해력 독립 이해도 검증"** 을 내세우는데 지금 문항이 한국어로만
    읽힙니다 (`quiz.js` 의 `promptSpeech()`). 픽토그램과 그림이 받치고 있지만,
    *"크메르어 노동자가 이 문항을 어떻게 이해하나요?"* 에 강하게 답하지 못합니다.
    **문항이 글로 돌아가는 순간 기능4 는 기존 필기시험이 됩니다**
  - **★ 조심할 것**: `answer` 는 `options` 의 인덱스입니다. 번역 배열의 길이나 순서가
    다르면 정답이 어긋납니다. **길이가 다르면 한국어로 되돌리는 규칙을 `qtext` 안에** 두세요
  - **곁들여**: `library.js` 의 `diffWords()` `negationFlipped()` 를
    `assets/review.js` 로 빼내 공용화하고, `content.js` 에서 번역을 입력할 때
    역번역도 받아 **부정이 뒤집혔으면 경고**합니다
  - **됐는지**: `W-4821-07`(크메르어)로 이해도 검증에 들어가면 문항과 선택지가
    크메르어로 나오고 크메르어로 낭독된다. 번역 없는 문항에는 "내 언어 번역 준비 중" 배지

  > **남는 한계** — 문항 문구는 `library` 의 검수를 거치지 않습니다. 문항을
  > 라이브러리에서 고르게 하면 검수가 따라오지만, *오답 선택지*까지 안전 문구
  > 라이브러리에 들어가 안전 지시로 뽑힐 위험이 생깁니다. 그래서 역번역 경고까지만
  > 합니다. 문항 검수는 **E. 나중에** 에 있습니다

- [ ] **A2. 언어별 검수 판정** — `library[].translations[code].status`

  - **어디**: `assets/store.js` (헬퍼) · `assets/seed.js` · `admin/library.js` ·
    `worker/learn.js` · `worker/home.js` · `admin/content.js` · `admin/proof.js`
  - **무엇**: 언어마다 검수 상태를 가집니다. 없으면 문구 전체의 `status` 를 따릅니다.
    `Store.phraseStatus(p, lang)` · `Store.phraseOk(p, lang)` 로 읽습니다.
    오역 신고도 `flags[].lang` 을 받아 **그 언어만** 중지합니다
  - **왜**: 지금은 `status` 가 문구 단위입니다. **크메르어만 오역이어도 문구 전체가
    내려가고, 인도네시아어·베트남어 노동자도 그 안전 지시를 함께 못 듣습니다**
  - **곁들여**: `seed.js` 의 `ph-3` 을 문구 전체 중지 → **인도네시아어만 중지**로
    바꿉니다. 그게 실제 상황이고 **시연이 더 좋아집니다** —
    "뜻이 뒤집힌 그 언어만 내렸고, 크메르어 노동자는 이 문구를 계속 듣습니다"
  - **됐는지**: `oper@safety.kr` 에서 `ph-3` 이 인도네시아어만 중지로 보이고,
    `W-4821-07`(크메르어) 수강 화면에는 그 문구가 **계속 보이고**,
    `W-4821-11`(인도네시아어) 화면에서는 **빠진다**

# E. 나중에 — 서버가 생긴 뒤 (3층)

지금은 서버가 없고 브라우저 저장소만 있어서 못 하는 것들입니다.

- **현장 실사진 hotspot** — `localStorage` 약 5MB 벽. **사진이 필요해지는 시점이
  서버가 필요해지는 시점입니다**
- **오프라인 우선 동작** — Service Worker 는 `file://` 에서 등록되지 않습니다
- **실제 6개 언어 음성** — 지금은 브라우저 음성합성입니다. **음성도 문구처럼
  검수 상태를 가져야 합니다**
- **문항 검수** — 문항 문구도 역번역 대조와 사람 승인을 거치게 (A1 의 남는 한계)
- **노동자 → 운영자 오역 신고 직결** — 지금은 홈에 안내만 있습니다
- **익명 유지 회신 채널** — 신고자를 식별하지 않는 티켓 번호로 "조치됐습니다" 회신
- **증빙 위조 검증** — 생성 시점 해시·타임스탬프
- **감독기관 제출 서식 연동** — **"면책" 표현 금지는 그대로**
- **문항 난이도 자동 관측** — 최초 통과율이 70~85% 밖으로 나가면 경고

# ★ 절대 지우지 말 것

기획 문서에서 온 제약입니다. **코드로 이미 지켜져 있고, 어디에 있는지 적었습니다.**
혼자 만들면 어기기 쉬워지니 오히려 더 봐야 합니다.

## 노동자 화면

| 무엇 | 어디 | 왜 |
|---|---|---|
| **`Store.reports` 에 신고자 식별값을 넣지 않는다** | `report.js` 저장 블록 | 익명성이 깨지면 신고가 멈추고, 재해를 미리 아는 방법이 사라집니다. `userId` `workerId` `author` 어느 것도 안 됩니다 |

| **이름을 감추면 `author` 를 빈 문자열로** | `talk.js` | 표시만 감추고 아이디를 담아 두면 화면 한 줄 고치는 것으로 익명이 풀립니다 |
| **미수강·미통과를 숨기는 경로를 만들지 않는다** | `my.js` 증빙 | 숨길 수 있는 증빙은 증빙이 아닙니다. 걸러 보기도, 결과순 정렬도 두지 않습니다 |
| **모든 안내에 음성을 병행한다** | 노동자 화면 전부 | 글자를 한 자도 읽지 않고 끝낼 수 있어야 합니다. `UI.audioButton()` |
| **터치 타깃 60px** | 노동자 화면 전부 | 장갑 낀 손으로 조작합니다. `min-height: var(--tap-min)` |
| **외국인등록번호·여권번호를 받지 않는다** | `my.js` | 사업장 내 식별번호로 충분합니다 |
| **검수된 문구만 안전 지시로** | `learn.js` `phrasesOf()` · `home.js` `pickTodayPhrase()` | 오역이 그대로 사고가 됩니다. 0개면 진행 자체를 막습니다 |
| **번역이 없는 문구를 조용히 숨기지 않는다** | `learn.js` | 안전 지시가 말없이 사라지는 쪽이 더 위험합니다. 한국어를 띄우고 "준비 중" 을 남깁니다 |
| **음성이 없으면 그 사실을 화면에 적는다** | `UI.voiceNote()` | 소리가 안 났는데 난 줄 알면, 글자를 못 읽는 사람은 아무것도 못 받은 채 통과합니다 |
| **한 문항에 한 번만 답한다** | `quiz.js` `answered()` | 그 자리에서 다시 풀 수 있으면 점수가 늘 100 이 되고 "최초 통과율" 이 뜻을 잃습니다 |
| **미통과는 노동자의 실패가 아니라 교육의 실패** | `quiz.js` `result-fault` | 이 문장이 빠지면 이 기능은 노동자를 걸러 내는 시험이 됩니다 |
| **답한 직후 어떤 사고가 되는지 말한다** | `quiz.js` `consequence` | 맞고 틀림만 알려 주면 다음에 또 같은 선택을 합니다 |
| **문항 3유형은 비문자 조작** | `quiz.js` `KIND` | hotspot · choice · match. 문항이 글로 돌아가면 기존 필기시험이 됩니다 |

## 전체

| 무엇 | 왜 |
|---|---|
| **외부 요청 0건** — CDN · 웹폰트 · 외부 이미지 · npm 금지 | 인터넷 없이 `file://` 로 열리는 것이 이 프로젝트의 확인 방법 전체입니다 |
| **`innerHTML` 금지** — `UI.el` 로 `textContent` | 설비 이름 한 줄로 화면이 깨지면 안 됩니다 |
| **ES 모듈 금지** — `var X = (function(){...})()` | `file://` 에서 CORS 로 막힙니다. 한 번 겪고 되돌린 기록이 devlog 에 있습니다 |
| **`localStorage` 직접 호출 금지** — `Store` 를 거친다 | 서버가 생기면 `store.js` 하나만 바꾸면 됩니다 |
| **색상만으로 상태 구분 금지** | 아이콘 + 글자 + 색 3중. 흑백으로 봐도 뜻이 남아야 합니다 |
