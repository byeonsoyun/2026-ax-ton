# 07. 지금 무엇을 하면 되는가

**"나 뭐 하면 되는지 알려줘" 라고 하면 Claude Code 가 이 문서를 봅니다.**

화면 11개는 전부 동작합니다. 남은 일은 **내 화면에 살을 붙이는 것**입니다.

---

## Claude Code 에게 — 이 문서를 쓰는 순서

1. `CLAUDE.md` 의 3단계로 **포지션을 먼저 확정**합니다 (브랜치 → `docs/devlog/<브랜치>.md` 의 `포지션:` 줄)
2. `docs/devlog/<브랜치>.md` 를 읽어 **이 사람이 이미 무엇을 했는지** 확인합니다
3. 아래에서 **자기 포지션 절만** 읽습니다. 다른 포지션 절은 남의 담당이라 읽을 필요가 없습니다
4. 그 절의 **"지금 상태"를 사용자에게 한 문단으로 말해 주고**, `- [ ]` 중 **맨 위 것 하나**를 제안합니다
   - 여러 개를 동시에 벌이지 않습니다. 하나 끝내고 커밋하는 편이 충돌이 적습니다
   - 사용자가 다른 것을 하고 싶다고 하면 그걸 합니다. 순서는 권장이지 강제가 아닙니다
5. 시작하기 전에 **그 화면을 브라우저에서 열어 지금 동작을 확인**하라고 안내합니다.
   골격이 이미 동작하므로, 무엇을 고치는지 눈으로 보고 시작할 수 있습니다
6. 한 항목이 끝나면 **이 문서의 `- [ ]` 를 `- [x]` 로 바꾸고** 개발일지와 함께 커밋합니다

> **주의** — 각 절의 **"절대 지우지 말 것"** 은 기획 문서에서 온 제약입니다.
> 코드로 이미 지켜져 있고, 지우면 제품의 전제가 무너집니다.
> 지워야 할 것 같으면 먼저 사용자에게 왜 그런지 물어보세요.

### "골격" 이 정확히 무슨 뜻인가

담당자가 정해지기 전에 흐름이 끊겨 있으면 아무도 확인을 못 해서, P1 이 여덟 화면을
**데이터가 끝까지 흐르는 지점까지** 만들어 두었습니다.

- 화면이 **실제 데이터로 동작합니다.** 빈 화면이 아닙니다
- 그 화면이 지켜야 하는 규칙은 **이미 코드로 들어가 있습니다.** 파일 맨 위 주석에 무엇을 지켰는지 적혀 있습니다
- 화면 맨 아래 **"여기부터 채우시면 됩니다"** 칸에 남은 일이 적혀 있습니다 (아래 목록과 같은 내용입니다)
- **담당자가 붙는 순간 그 화면의 주인은 담당자입니다.** P1 은 더 손대지 않습니다

### 지금 이어지는 전체 흐름

```
운영자가 문구를 검수 (기능9)
  → 담당자가 교육을 만든다 (기능2)
    → 노동자가 듣는다 (기능3)
      → 이해했는지 확인한다 (기능4)
        → 담당자가 취약 항목을 본다 (기능6)

```

## 지금 상태

네 화면이 다 동작합니다. 홈에서 오늘의 안전 문구가 음성과 함께 뜨고, 수강→검증→완료
3단계가 픽토그램으로 보이고, 신고는 그림 두 번 눌러 접수되고, 게시판은 익명으로 글과
댓글이 저장되고, 마이페이지는 수강 증빙을 인쇄할 수 있습니다.

## ★ 절대 지우지 말 것

| 무엇 | 어디 | 왜 |
|---|---|---|
| **`Store.reports` 에 신고자 식별값을 넣지 않는다** | `report.js` 저장 블록 | 익명성이 깨지면 신고가 멈추고, 재해를 미리 아는 방법이 사라집니다. `userId` `workerId` `author` 어느 것도 안 됩니다 |
| **"내가 낸 신고"를 만들지 않는다** | `report.js` · `my.js` | 익명이라 가려낼 수 없습니다. 그게 익명이라는 뜻이고, 화면에 그 이유가 적혀 있습니다 |
| **이름을 감추면 `author` 를 빈 문자열로** | `talk.js` | 표시만 감추고 아이디를 담아 두면 화면 한 줄 고치는 것으로 익명이 풀립니다 |

| **모든 안내에 음성을 병행한다** | 네 화면 전부 | 글자를 한 자도 읽지 않고 끝낼 수 있어야 합니다. `UI.audioButton()` 을 쓰세요 |
| **터치 타깃 60px** | 네 화면 전부 | 장갑 낀 손으로 조작합니다. `min-height: var(--tap-min)` |
| **외국인등록번호·여권번호를 받지 않는다** | `my.js` | 사업장 내 식별번호로 충분합니다 |

**열지 말 것** — `admin/content.*` `admin/dashboard.*` (P3) · `admin/setup.*` (P1) · `worker/**` (P1·P2)

## 지금 상태

두 화면이 다 동작합니다. 라이브러리에서 오역 신고를 접수하면 그 문구가 즉시 사용
중지되고 기능2 선택지에서 사라집니다. 역번역 대조는 부정이 뒤집힌 경우(`ph-3`)를
크게 경고하고, 말만 바꿔 쓴 경우(`ph-5`)는 낱말 개수만 알립니다. 증빙 화면은
교육일지를 그려 브라우저 인쇄로 PDF 가 됩니다.

## ★ 절대 지우지 말 것

| 무엇 | 어디 | 왜 |
|---|---|---|
| **오역 신고는 접수하는 순간 `stopped`** | `library.js` `fileFlag()` | 확인한 뒤 내리는 순서가 아닙니다. 오역이 걸린 문구가 현장에 한 시간 더 붙어 있는 것이 더 위험합니다 |
| **부정 뒤집힘만 크게 경고한다** | `library.js` `negationFlipped()` | 낱말이 다른 것과 같은 세기로 표시하면 운영자가 표시를 무시하게 되고, 정작 뜻이 뒤집힌 문구가 지나갑니다 |
| **번역 없는 문구를 `reviewed` 로 못 올린다** | `library.js` `setStatus()` | 기능2 선택지에 빈 문구가 올라갑니다 |
| **AI 여기까지 — 승인은 사람** | `library.html` `.ai-note` | AI 가 어디까지 관여했는지 보이지 않으면 안전 정보를 신뢰할 근거가 없습니다 |
| **증빙은 쓰는 키가 없다** | `proof.js` | 사본을 만들지 않으니 고칠 경로도 없습니다. "생성 후 수정 불가" 를 규칙이 아니라 구조로 만든 것입니다. `.save()` `.update()` 를 추가하지 마세요 |
| **미이수자·미통과자를 숨기지 않는다** | `proof.js` `renderRows()` | 걸러 보기도, 결과순 정렬도 두지 않습니다. 정렬만 바꿔도 아래로 밀어내는 통로가 됩니다. 인쇄에서도 옅게 만들지 않습니다 |
| **"면책" 이라고 쓰지 않는다** | `proof.html` `proof.js` | 증빙은 교육 실시의 기록일 뿐 법적 책임을 대신하지 않습니다 |
| **서명이 아니라 이해도 검증 결과** | `proof.html` `.proof-note` | 서명은 참석의 증거일 뿐이라는 데서 이 서식이 출발했습니다 |
