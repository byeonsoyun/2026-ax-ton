### 지난 항목들에서 생긴 규칙 (새 코드가 어겨서는 안 되는 것)

- 문항 문구·선택지는 **`Store.qtext(q, lang, field)`** 로만 읽습니다.
  화면에서 `q.i18n` 을 직접 뒤지지 않습니다 — 번역 배열 길이 검사가 그 함수 한 곳에 있고,
  어긋나면 `answer` 인덱스가 다른 선택지를 가리킵니다
- 문구 판정은 **`Store.phraseOk(p, lang)`** 로만 읽습니다.
  `p.status` 를 직접 보면 언어별 판정이 무시되고, 한 언어의 오역으로
  다른 언어 노동자가 안전 지시를 잃습니다
- 음성이 **났는지 안 났는지를 브라우저 이름으로 넘겨짚지 않습니다.**
  `UI.speak()` 가 실제 신호를 보고 판정하고, 판정은 `UI.voiceNote()` 와
  버튼 그림(🔊 → 🔇)에 함께 나옵니다. 넘겨짚기 시작하면 다음에 나올
  인앱 브라우저를 또 놓칩니다
- 로그인 화면의 자동 채우기는 **`Seed.fillIfEmpty()`** 만 부릅니다.
  `Seed.fill()` 로 바꾸면 담당자가 등록한 사업장이 새로고침마다 예시로 되돌아갑니다
- 교육 기한 배지는 **`UI.dueBadge(dueAt)`** 로만 그립니다.
  같은 계산을 화면마다 두면 한쪽만 고쳐져서 콘텐츠 화면과 대시보드가
  서로 다른 날짜를 말합니다
- 새로 만든 안전 문구는 **`status: 'waiting'`(검수 대기) 으로만 들어갑니다.**
  추가 폼에서 `reviewed` 를 만들 수 있게 하면 검수를 지나지 않은 문구가 그대로
  안전 지시가 되고, 기능9 라는 화면이 있는 이유가 사라집니다
- 항목을 끝내면 **화면 안 "여기부터 채우시면 됩니다" 칸에서도 그 줄을 지웁니다.**
  그리고 `tests/test-docs.js` 의 `DONE` 목록에 한 줄 더합니다 — 그래야 다음에
  또 어긋나면 검사가 잡습니다. 문서와 화면이 다른 말을 하면 사람은 화면을 믿습니다
- 이 규칙들은 맨 아래 **"절대 지우지 말 것"** 표에도 들어 있습니다

### 회귀 검사 돌리는 법

`src/` 는 의존성이 0 입니다. `jsdom` 은 **저장소 밖**에 깔고 `NODE_PATH` 로 가리킵니다.
자세한 것은 [`../tests/README.md`](../tests/README.md).

```bash
mkdir -p ~/jsdom-box && cd ~/jsdom-box && npm i jsdom     # 한 번만
cd <저장소> && NODE_PATH=~/jsdom-box/node_modules node tests/run-all.js
```

**공용 파일(`src/assets/`)을 고쳤으면 반드시 돌립니다.** 11개 화면이 다 읽습니다.
검사가 깨지면 먼저 "내가 바꾼 것이 맞는 변화인가" 를 보세요 —
예시 데이터를 바꾸면 개수 기대값이 함께 깨집니다. 그건 검사를 고치는 것이 맞습니다.

# E. 나중에 — 서버가 생긴 뒤 (3층)

지금은 서버가 없고 브라우저 저장소만 있어서 못 하는 것들입니다.

- **현장 실사진 hotspot** — `localStorage` 약 5MB 벽. **사진이 필요해지는 시점이
  서버가 필요해지는 시점입니다**
- **오프라인 우선 동작** — Service Worker 는 `file://` 에서 등록되지 않습니다.
  다만 **https 배포에서는 등록됩니다** — `V2` 이후 E층에서 가장 먼저 꺼낼 수 있는
  항목입니다. "현장 인터넷이 약하다" 는 이 제품의 전제와도 맞습니다
- **실제 6개 언어 음성** — 지금은 브라우저 음성합성입니다. **음성도 문구처럼
  검수 상태를 가져야 합니다**
- **문항 검수** — 문항 문구도 역번역 대조와 사람 승인을 거치게 (A1 의 남는 한계)
- **노동자 → 운영자 오역 신고 직결** — 지금은 홈에 안내만 있습니다
- **익명 유지 회신 채널** — 신고자를 식별하지 않는 티켓 번호로 "조치됐습니다" 회신
- **증빙 위조 검증** — 생성 시점 해시·타임스탬프
- **감독기관 제출 서식 연동** — **"면책" 표현 금지는 그대로**
- **문항 난이도 자동 관측** — 최초 통과율이 70~85% 밖으로 나가면 경고

| **음성이 없으면 그 사실을 화면에 적는다** | `UI.voiceNote()` | 소리가 안 났는데 난 줄 알면, 글자를 못 읽는 사람은 아무것도 못 받은 채 통과합니다 |
| **한 문항에 한 번만 답한다** | `quiz.js` `answered()` | 그 자리에서 다시 풀 수 있으면 점수가 늘 100 이 되고 "최초 통과율" 이 뜻을 잃습니다 |
| **미통과는 노동자의 실패가 아니라 교육의 실패** | `quiz.js` `result-fault` | 이 문장이 빠지면 이 기능은 노동자를 걸러 내는 시험이 됩니다 |
| **답한 직후 어떤 사고가 되는지 말한다** | `quiz.js` `consequence` | 맞고 틀림만 알려 주면 다음에 또 같은 선택을 합니다 |
| **문항 3유형은 비문자 조작** | `quiz.js` `KIND` | hotspot · choice · match. 문항이 글로 돌아가면 기존 필기시험이 됩니다 |
| **번역 배열 길이가 다르면 한국어로 되돌린다** | `assets/store.js` `qtext()` | `answer` 는 `options` 의 인덱스입니다. 길이나 순서가 어긋나면 정답이 다른 선택지를 가리키고, 틀린 작업을 맞다고 가르칩니다. 이 검사는 `qtext` 한 곳에만 둡니다 — 화면마다 흩어 놓으면 언젠가 한 곳이 빠집니다 |
| **문항을 화면에서 `q.i18n` 으로 직접 읽지 않는다** | `quiz.js` `qt()` · `proof.js` | 위 검사를 지나가는 통로가 하나여야 합니다 |

## 관리자 · 운영자 화면

| 무엇 | 어디 | 왜 |
|---|---|---|
| **검수 완료된 문구만 선택지에** | `content.js` `usablePhrases()` | 고를 수 있게 두는 것 자체가 위험합니다 |
| **등록한 언어만 나온다** | `content.js` `buildLangPicker()` | 기능1 에서 등록하지 않은 언어가 교육에 들어가면 안 됩니다 |
| **문항 없이는 발급할 수 없다** | `content.js` `draftSteps()` | 문항이 없으면 이해를 확인할 수 없고, 교육 완료로 기록할 근거가 없습니다 |
| **취약 항목이 이수율보다 크다** | `dashboard.html` `.card.feature` · `.kpi-row.small` | 위계가 뒤바뀌면 이수율만 보고 교육을 안 고칩니다 |
| **화면에 반드시 남아야 하는 문장 세 개** | `dashboard.html` `.policy-note` | ① 노동자 평가가 아니라 콘텐츠 개선 신호 ② 미통과는 교육의 실패 ③ 인사·평가 목적 내보내기 없음 |
| **신고에 조치 상태만 쓴다** | `dashboard.js` `setReportStatus()` | 신고자 식별값을 새로 넣으면 익명이 깨집니다 |
| **정답률 막대에 등급 글자를 함께** | `dashboard.js` `grade()` | 색만으로 구분하지 않습니다. 흑백으로 봐도 뜻이 남아야 합니다 |
| **신고할 때 언어를 반드시 고른다** | `library.js` `renderFlagLangs()` | 기본값을 두면 손대지 않고 접수한 순간 엉뚱한 언어가 내려가거나, 한 언어의 오역으로 다른 언어 노동자까지 안전 지시를 잃습니다 |
| **언어별 판정은 엄한 쪽을 따른다** | `assets/store.js` `phraseStatus()` | 중지 > 대기 > 완료. 문구 전체가 중지면 어느 언어로도 나가지 않습니다 |
| **한 언어를 고친 것이 문구 전체를 되살리지 않는다** | `library.js` `setStatus()` | 언어별 판정으로는 그 언어의 신고만 닫습니다 |
| **오역 신고는 접수하는 순간 중지** | `library.js` `fileFlag()` | 확인한 뒤 내리는 순서가 아닙니다. 오역이 한 시간 더 붙어 있는 것이 더 위험합니다 |
| **선택지 번역을 덜 채우면 저장하지 않는다** | `content.js` `collectI18n()` | 정답은 번호로 정해집니다. 한 칸이 비면 정답이 다른 선택지를 가리킵니다 |
| **한국어로만 제공된 문항을 증빙에서 숨기지 않는다** | `proof.js` `renderQuiz()` · `.proof-qlang` | 인쇄에서도 옅게 만들지 않습니다. 숨길 수 있는 증빙은 증빙이 아닙니다 |
| **부정 뒤집힘만 크게 경고한다** | `assets/review.js` `negationFlipped()` | 낱말 차이와 같은 세기로 표시하면 운영자가 표시를 무시하게 되고, 정작 뜻이 뒤집힌 것이 지나갑니다 |
| **번역 없는 문구를 `reviewed` 로 못 올린다** | `library.js` `setStatus()` | 기능2 선택지에 빈 문구가 올라갑니다 |
| **증빙은 쓰는 키가 없다** | `proof.js` · `my.js` | 사본이 없으니 고칠 경로도 없습니다. "수정 불가" 를 규칙이 아니라 구조로 만든 것입니다. `.save()` `.update()` 를 추가하지 마세요 |
| **미이수자·미통과자를 숨기지 않는다** | `proof.js` `renderRows()` | 걸러 보기도, 결과순 정렬도 없습니다. 정렬만 바꿔도 밀어내는 통로가 됩니다. 인쇄에서도 옅게 만들지 않습니다 |
| **"면책" 이라고 쓰지 않는다** | `proof.html` `proof.js` | 증빙은 교육 실시의 기록일 뿐 법적 책임을 대신하지 않습니다 |
| **서명이 아니라 이해도 검증 결과** | `proof.html` `.proof-note` | 서명은 참석의 증거일 뿐이라는 데서 이 서식이 출발했습니다 |
| **기한 판정은 `UI.dueBadge` 한 곳에서** | `assets/ui.js` `dueBadge()` | 기능2 의 발급 목록과 기능6 의 대시보드가 같은 함수를 씁니다. 계산을 화면마다 두면 한쪽만 고쳐져 두 화면이 서로 다른 날짜를 말합니다 |
| **기한이 없는 것도 상태로 보여 준다** | `ui.js` `dueBadge()` | 기한이 없을 때 배지를 그리지 않고 넘기면, 담당자는 기한을 안 넣은 것을 알 방법이 없습니다. "미정" 을 적습니다 |
| **기한을 발급 조건으로 만들지 않는다** | `content.js` `draftSteps()` | 기한이 없다고 교육 발급을 막으면 급한 교육을 내보낼 수 없습니다 |
| **AI 경계 표시** | `library.html` `content.html` `dashboard.html` `.ai-note` | 기능9 "AI 여기까지 · 승인은 사람" · 기능2 "문구를 새로 쓰지 않는다" · 기능6 "AI 개입 없음" |

## 전체

| 무엇 | 왜 |
|---|---|
| **외부 요청 0건** — CDN · 웹폰트 · 외부 이미지 · npm 금지 | 인터넷 없이 `file://` 로 열리는 것이 이 프로젝트의 확인 방법 전체입니다 |
| **`innerHTML` 금지** — `UI.el` 로 `textContent` | 설비 이름 한 줄로 화면이 깨지면 안 됩니다 |
| **ES 모듈 금지** — `var X = (function(){...})()` | `file://` 에서 CORS 로 막힙니다. 한 번 겪고 되돌린 기록이 devlog 에 있습니다 |
| **`localStorage` 직접 호출 금지** — `Store` 를 거친다 | 서버가 생기면 `store.js` 하나만 바꾸면 됩니다 |
| **첫 방문 자동 채우기는 `Seed.fillIfEmpty()` 만** — `assets/login.js` | `fill()` 은 덮어씁니다. 담당자가 등록한 사업장이 새로고침마다 예시로 되돌아갑니다. 그리고 **로그인 확인보다 뒤에서** 부릅니다 — 앞에 두면 계정이 지워진 세션을 되살려 로그인하지 않은 사람이 화면 안으로 들어갑니다 |
| **색상만으로 상태 구분 금지** | 아이콘 + 글자 + 색 3중. 흑백으로 봐도 뜻이 남아야 합니다 |
